O **Kind Pet** é um projeto de desenvolvimento web voltado à divulgação de animais para adoção, com o objetivo de facilitar o acesso às informações dos animais e incentivar a adoção responsável.

O projeto está em desenvolvimento e busca oferecer uma interface intuitiva, organizada e responsiva, aproximando pessoas interessadas em adotar de animais que precisam de um lar.

* Layout responsivo em desenvolvimento.

## Como executar o projeto

### Pré-requisitos

* [Node.js](https://nodejs.org/)
* npm, instalado junto com o Node.js.

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/bruno-rodrigues-dev/kind-pet.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd kind-pet
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse no navegador o endereço exibido no terminal.
